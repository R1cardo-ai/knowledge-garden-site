# 图1与图2的动效差异计划

## 目标

以图1对应的主页展示模板为动效参照，为图2总览页补上源码中明确存在、而主站当前尚未复现的效果。只规划动效迁移，不改变图2的页面结构、档案数据和操作行为。

## 对照依据

- 图1的页面源码是 [showcase.html](../public/ui-kit/templates/showcase.html)，共享动效定义在 [endfield.css](../public/ui-kit/assets/endfield.css)，数字读数和视差逻辑在 [fx.js](../public/ui-kit/assets/fx.js)。图1截图里的字标、黄色标语、右侧线稿、更新横带和大号版本号都能在这份模板中找到对应元素。
- 图2主站结构在 [page.tsx](../app/page.tsx)，主要样式和动画在 [endfield-desktop-controls.css](../app/endfield-desktop-controls.css)，主题转场在 [theme-transition.ts](../lib/theme-transition.ts)。
- 静态截图本身不能证明元素正在运动；图1“已有动效”的判断以模板源码中的动画类、关键帧、事件监听和动效规则为准。

## 三轮提炼

### 第一轮：从图1页面结构找候选效果

找到六类候选：顶端三色条、KNOWLEDGE / GARDEN 字标、黄色标语、档案计数、最近更新横带、最新版本大号数字；另有鼠标视差。

### 第二轮：核对图1源码中的实际触发方式

- 字标使用 `ef-in-drive`，GARDEN 延迟 140ms；标语使用 `ef-in-stroke`，延迟 420ms 后擦入 420ms。
- 顶端三色条使用 `ef-in-sweep`，一次扫入 600ms。
- 计数使用 `data-fx-load`，约 600ms 内从乱序字符逐个锁定为真实数值，并按字段错开启动。
- 更新 ticker 复制一组内容形成无缝循环，周期 60 秒；悬停或键盘聚焦时暂停。开启减少动态效果后停止循环，保留可手动横向浏览的内容。
- 最新版本号在悬停或聚焦时由描边逐步填实，同时 `data-fx-host` 触发数字乱序锁定。
- 鼠标移动更新 `--mx / --my`：斜纹背板与纸张线稿向相反方向轻移，构成双层视差。

### 第三轮：与图2当前实现去重并确定缺口

图2已经有通用分段淡入、档案 SVG 描线、下方内容滚动显现、计数递增、线稿轻量跟随鼠标、更新条扫光、最新版本号入场、弹层和主题圆形转场。因此计划不再重复添加这些基础效果。差异集中在下表。

## 差异与计划

| 优先级 | 图1源码中的效果 | 图2当前状态 | 计划迁移 |
| --- | --- | --- | --- |
| P0 | 三色页首条从左向右扫入，600ms | 三色条由 `.site-shell::before` 静态绘制 | 页面首次进入时扫过一次；不做循环闪烁。减少动态效果时显示静态色条。 |
| P0 | KNOWLEDGE 由左向右裁切推入，GARDEN 晚 140ms | 两行字标作为同一个段落整体淡入上移 | 分别对两行应用裁切显现和轻微横向归位，保持第二行晚 140ms，保留当前字标尺寸和布局。 |
| P0 | 黄色马克笔底色从左侧擦入，420ms 延迟 + 420ms 动画 | 黄色强调块已存在，但随整段标题普通淡入 | 将当前高亮片段改为底色擦入，标题文字不抖动、不逐字跳动；保留现有换行与颜色。 |
| P1 | 首页读数由乱码逐位锁定为真值 | `AnimatedCount` 从 0 平滑递增到真值 | 首次加载时改为短促的数字/字母锁定效果；档案新增、删除后的数值变化仍用当前平滑递增。无障碍名称始终读取真实数值，动画不暴露乱码。 |

## 实施顺序

1. **首屏识别动效**：三色条扫入、两行字标分层推入、黄色标语擦入。先完成这组，以图1首页第一眼的节奏为准。
2. **数据与浏览节奏**：实现首次读数锁定效果，再接入最近更新 ticker；保留真值、链接、键盘可达性和手动横向滚动。
3. **舞台与版本交互**：加入纸张/斜纹双层视差和最新版本号悬停/聚焦填色。
4. **适配与验收**：对照图1和图2的桌面首屏；检查浅色/深色主题、不同桌面宽度、键盘操作、页面切换和 `prefers-reduced-motion`。验收时确认 ticker 无缝、可暂停、减动模式静止，计数和版本号始终可读且不改变档案数据。

## 明确不列为图1独有缺口的效果

- SVG 线稿描边：图1模板中的 SVG 路径没有描边动画；图2当前已实现路径逐组描绘。
- 最新内容区的入场：图1模板没有为 `.latest` 指定进入动画；图2当前已有滚动显现和大号版本号入场。
- 主题圆形扩散和斜切页面转场：两套代码都已有相近实现，不重复迁移。
- 按钮悬停、按下、弹层开合、减少动态效果支持：两套实现均已有对应规则；后续只做实际交互验证。
