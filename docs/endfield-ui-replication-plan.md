# Endfield UI 桌面网页完整落地规划

## 当前主站的设计约定

- 产品家族与深度：Endfield / 复杂级（`endfield + complex`）；复杂度体现在桌面外壳、展陈封面、记录工作区、筛选、表单、详情和更新日志的系统级覆盖，不增加虚构状态信息。
- 页面职责：首页上半部使用展示型档案封面；快速记录与档案浏览区使用控制台式工作区；单条记录详情、表单和帮助样张以阅读优先。
- 主任务：快速捕获一条知识或成果，再通过搜索、筛选、排序和列表/卡片视图找回记录。
- 主站默认外观：深石墨与黑色、白色等高线低强度显示（当前深色桌面不透明度 `0.07`）、信号黄只表达当前项和主要操作；无默认人物图，正文优先保证舒适阅读。浅色主题作为可选外观，使用纸白与墨色并保留深色命令栏。

## 已确定的变体

- 变体：标准（yellow / neutral / standard / contours / standard / full）
- 主视觉：个人档案中的真实年份、记录数和等高线纹理；不用官方游戏素材。
- 页面类型：档案主页以控制台为主，单条档案和长文使用阅读版式；另提供展示、组件、动效和规则对照样张。
- 平台范围：桌面网页。手机 App 模板和 Flutter 示例不纳入本网站。

## README 中适用于桌面网页的能力

1. 三类页面范式：展示页、阅读页、控制台。
2. 网页工具套件：统一 token、控件、深浅主题、等高线、切角、焦点与动效。
3. 六个可运行样张：展示、阅读、控制台、部件总览、动效演示、正反例对照。
4. 四种预设及独立轴：强调色、纸色、切角、底纹、密度、动效。
5. 键盘可达、读屏语义、系统减少动态效果支持和本地字体许可。

## 项目实施结构

- 保留现有 Next/vinext 应用和知识档案数据流程；它能够继续提供主站和新增路由，无需为静态样张迁移框架。
- 主站承载真实档案功能和统一主题选择。
- 新增 `/ui-kit` 作为桌面样张入口；样张使用 skill 随附的网页 CSS、动效、变体和圆盘工具，以便完整展示已有能力。
- 样张资产、Saira 字体与 OFL 许可在本地自托管；移除对 Google Fonts 的运行时依赖。
- 桌面范围包含六个网页样张；不复制移动端 app.html 或 Flutter 工程。

## 与 skill 模板的内容差异

- 用“知识花园”和个人档案语境取代 ACME、木箱线稿和演示品牌。
- 控制台、展示页和阅读页的指标、记录与更新信息以本站可核验数据为来源。
- 保留部件与反例页面作为明确的设计预览，不把演示数据伪装成真实档案。

## 验收范围

- 六个桌面样张都能从 `/ui-kit` 打开，且返回主站路径清楚。
- 四组预设及独立外观参数、浅深切换、主题记忆可用。
- 动效展示可重放；减少动态效果时不播放入场或循环装饰。
- 键盘焦点、读屏标签、真实数据、红色仅用于删除、无游戏素材。
- 主站原有记录新增、编辑、删除确认、搜索筛选、本地保存与 JSON 备份能力保留。
- 总览与知识/获奖页在深色和浅色主题下均保持相应纸面、文字、线稿和选中态配色；主题切换不能只更新按钮状态。
