# 项目手册

本手册汇总项目需求、长期决策和 agent 的权威信息入口。当前运行版本及产品更新日志以 `app/archive/page.tsx` 为准；历史记录不覆盖当前实现状态。

## 当前约束与权威来源

- 网站只做桌面端；不新增手机专属界面、手机优化或手机验收项。
- 可见的网站或 UI 更新需同步站内版本、更新日志、首页更新展示及 `public/ui-kit/templates/` 对应展示数据。
- 网站更新经验证后同步 GitHub 与生产站点；发布后等待部署并核对线上版本和改动入口。
- 站内版本与托管平台部署版本是不同维度。纯文档和托管操作不单独递增站内版本。
- 当前桌面实现与验收结论见 [`当前桌面验收.md`](当前桌面验收.md)。
- 产品设计来源见 [`设计规范与规划.md`](设计规范与规划.md)；外部产品观察见 [`design-references.md`](design-references.md)。
- 历史进度、旧计划和历史验收汇总见 [`archive/2026-10.md`](archive/2026-10.md)。
- 个人档案和素材发布操作见 [`本地档案与素材操作.md`](本地档案与素材操作.md)。

## 版本与更新日志要求

- 每次发布可见的产品或 UI 更新，都必须递增站内版本号，使用 `v主版本.次版本.修订版本` 格式。
- 每次递增版本号，都必须在 `app/archive/page.tsx` 的 `updateLogs` 中新增对应日志，包含版本号、日期、标题和具体改动项。
- `currentVersion` 必须与 `updateLogs` 中最新一条日志的 `version` 保持一致。
- Sites 托管版本号与站内产品版本号是两个独立维度；发布托管版本时不替代站内更新日志。

## 已确认决策

- 站内版本按连续修订号递增；纯文档记录或内部托管操作不单独增加站内版本。
- 2026-09-17 的历史决策曾将 `app/page.tsx` 作为日志来源，该路径已被后续实现取代。当前唯一规范源是 `app/archive/page.tsx`，不得维护第二套更新日志。
- 每次发布前核对 `currentVersion`、`updateLogs[0].version` 与本次可见改动一致。
