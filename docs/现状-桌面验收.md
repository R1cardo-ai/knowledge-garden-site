## 2026-10-29 弹层关闭闪烁修复

当前产品 v1.0.231。用户报告点击更新日志弹窗的关闭按钮时页面会闪一下。逐帧复现（无头 Chrome 1660×920、暗色主题、逐合成帧亮度统计）确认：弹窗淡出后遮罩在弹层卸载前回弹为整屏 68% 压暗约 60 毫秒，再随整体卸载消失，形成一次暗闪。原因是遮罩退场 260ms 短于弹层 320ms（抽屉 340ms），而 `tw-animate-css` 的退场填充模式默认为 `none`，动画结束即回到 `opacity: 1`；Base UI 又要等弹层退场结束才卸载遮罩。

修复为 `app/endfield-desktop-controls.css` 中一条无层级规则：处于 `data-closed` 的 `dialog-overlay`、`sheet-overlay`、`alert-dialog-overlay` 使用 `animation-fill-mode: forwards`。入场动效、关闭节奏、深浅主题、减少动态效果与键盘关闭全部保留；未改档案 schema、存储键、排序或页面内容。

证据：修复前更新日志关闭有 6 帧最亮像素 111（平均亮度 23.36，正常页面 45.6）的压暗帧，修复后无任何压暗帧，遮罩 276ms 淡到 0 并在 342ms 随弹层卸载；详情抽屉关闭同样无回落。三个遮罩槽位计算值均为 `forwards`。lint、类型、`npm test`、生产与两套静态导出构建均通过。详见 [`v1.0.231 验收与完成审计`](validation/验收-历史记录汇编.md#source-c36464f165eb)、[`逐帧数据`](validation/v1.0.231-overlay-exit/frame-luminance.json) 与 [`发布记录`](validation/v1.0.231-overlay-exit/deployment.json)。

已发布：GitHub `source` `01684d3`、`main` `611a9a0`。Cloudflare Pages 线上 `https://knowledge-garden-site.pages.dev/archive` 与 GitHub Pages `https://r1cardo-ai.github.io/knowledge-garden-site/` 均已显示 v1.0.231：两处 CSS 含 `animation-fill-mode:forwards` 规则、档案页块与首页更新条均出现 v1.0.231。生产站真实浏览器复跑关闭流程 48 帧，无压暗帧，更新日志 243 条，控制台无报错。
