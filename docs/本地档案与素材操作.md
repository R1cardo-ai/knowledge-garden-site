# 本地档案与素材操作

按需阅读：浏览器档案备份、迁移与恢复；发布素材核对；首页精选偏好行为。文中历史日期与版本仅代表对应变更时的记录。

## 本地档案备份与域名迁移

适用版本：v1.0.205，快照 schema v2。尚未发布；本文是操作说明，不代表已执行迁移。

## 日常备份

1. 在保存了档案的原浏览器、原站点打开个人档案。
2. 点击“导出快照”，保留下载的 JSON 文件；涉及个人信息时不要把文件放进公开网站目录或 Git。
3. 版本 2 快照包含 entries、稳定条目 ID 和 relatedRefs 关联关系。旧数组及 version 1 快照仍可导入。
4. 如显示保存失败，在关闭页面前导出当前快照；内存中的修改可能尚未写入浏览器。

## 读取异常恢复

1. 出现恢复提示时，先下载“原始备份”。此文件按原始文本保存，可能不是有效 JSON，不要直接覆盖它。
2. 在副本上检查或修复 JSON，或选择此前导出的有效快照。
3. 点击“导入有效快照”，核对确认框中的替换条数，再决定是否覆盖。取消不会解除写入保护。
4. 导入后核对标题、笔记、关联及记录数量，再刷新确认。没有可用副本时保留原始文件，避免清空浏览器数据。

## 更换域名、协议、端口或浏览器

localStorage 按 origin 隔离。localhost:5199、127.0.0.1:5199、其他端口、HTTP/HTTPS 和新域名是不同存储空间，链接本身不能传输档案。

1. 在旧地址导出快照，保持旧地址的数据可访问。
2. 在新地址导入。若新地址已有档案，先分别导出两个地址的数据；当前导入是替换，不是合并。
3. 核对全部数量、典型长笔记、证明链接及稳定 ID 关联；刷新后再核对。
4. 确认新地址数据完整后仍保留旧快照。主题、侧栏和个人背景设置不在档案快照中，需要在新地址重新设置。

## 本地构建与回退

- `npm test`：运行存储、共享数据、URL、笔记、关联与版本检查。
- `npx tsc --noEmit`：类型检查。
- `npm run build`（或 `npm run build:validate`）：五阶段本地生产构建，输出 `.local-build/`；只清理此构建目录，不清理旧 dist。
- `npm start -- --ip 127.0.0.1 --port 5201`：运行该生产构建。`npm run check:production` 检查此端口的页面、资源与 404；不是浏览器交互验收。
- `npm run dev -- --host 127.0.0.1 --port 5199`：源码开发预览。开发模式使用 Vinext，生产构建保留 Cloudflare 插件。
- 旧根目录静态产物和压缩包不是最新源码预览，不要将它们当作新版构建证据。
- 回退前先导出当前数据。schema v2 的关联字段可能被旧程序丢弃，因此不要在唯一一份浏览器数据上直接运行旧版本；使用独立 origin 和副本验证。
- 当前 Git 有暂存删除与同名未跟踪源文件并存；禁止用 reset/clean 或批量提交来代替产物整理。回退产物须另存并标明版本、日期及构建方式。

## 首页精选偏好兼容说明

日期：2026-10-29；引入版本：v1.0.225。

首页精选采用独立的 localStorage 键 `knowledge-garden-featured-entry`，值为已有档案的稳定 ID。不会新增或改写档案字段，不升级 schema，旧数组与 v1/v2 快照继续使用现有兼容路径。

没有偏好时不进行迁移写入，自动使用最近更新记录。指定 ID 不存在（删除、导入其他快照或清空档案）时同样自动回退；空档案展示空状态。保留失效的偏好 ID，因此重新导入包含同一稳定 ID 的备份后可以恢复选择；不会按同名标题猜测绑定。

在档案总览的“首页精选”中选择记录或“自动选择最近更新”。写入失败会提示，界面维持上次成功选择。偏好读取失败不会阻止首页档案展示。跨标签页通过 storage 事件更新，返回缓存页通过 pageshow 刷新。

偏好仅属于当前浏览器及来源，不纳入档案 JSON 备份；跨设备、跨域迁移后可重新选择。旧版网站忽略这个额外键，回退版本时不需要改动档案。此设计不改变主题、背景、导入导出或关系字段。
